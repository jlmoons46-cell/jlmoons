# **App Name**: JLMOONS

## Core Features:

- Dynamic Navigation & CTAs: A sticky header featuring a logo, clear navigation links, and priority calls-to-action (Telegram, Contact, Start Recovery) with a backdrop blur effect for immediate accessibility and credibility.
- Impact-Driven Hero Section: A dominant hero area showcasing a compelling headline, pain-driven subtext, key trust-building statistics ($8M+ recovered, 94% success), and prominent buttons for initiating recovery requests.
- Comprehensive Service Overview: Presents a grid of six distinct service cards (e.g., Wallet Recovery, Hacked Account Recovery) each with an icon, title, short description, and 'Learn more' link to highlight the breadth of expertise.
- Guided Recovery Process: An intuitive 4-step guide (horizontal timeline for desktop, vertical stack for mobile) outlining the simplified recovery journey, making the process feel clear and manageable.
- Secure Recovery Request Form: A validated multi-field form, using React Hook Form and Zod for robust validation, enabling users to securely submit their recovery details and type of asset loss.
- AI-Powered Recovery Inquiry Assistant: An AI tool integrated within the recovery request form that guides users by asking clarifying questions and suggesting relevant details to ensure comprehensive and accurate input for efficient assessment by recovery specialists.
- Curated Knowledge Hub Display: Showcases blog articles fetched from a CMS, presenting each entry with a title, category tag, and short description to build authority, provide education, and enhance SEO.

## Style Guidelines:

- Dominant Brand Color: Deep Navy Blue (#091731) to serve as a primary background, evoking professionalism, stability, and trust within a dark theme.
- Accent Color: Rich Gold (#EBBF31) used for key elements, symbolizing value, success, and high-quality service, providing bright contrast.
- Highlight Color: Modern Teal (#48B3BA) to strategically draw attention and add a sophisticated, tech-oriented touch to interactive elements and highlights. (User-requested)
- Text Color: Soft White (#F2F2F2) ensuring excellent readability against the dark backgrounds across all content.
- Headings: 'Playfair' (serif, display-style) for a high-end, authoritative feel. Body: 'Inter' (sans-serif) for clean, objective readability.
- Clean, crisp vector icons (e.g., feather icons, heroicicons) for service cards and step indicators, aligning with the modern, precise aesthetic.
- Utilize rounded cards and soft borders to create a polished, accessible feel, incorporating grid layouts for structured content presentation and responsive adaptation for mobile devices.
- Implement subtle glow accents and gradients, particularly in hero sections and interactive elements, to enhance visual depth and a sense of digital sophistication.
- Subtle and elegant motion, such as scroll-triggered animations (fade-ups for headlines, sequential reveals), and engaging hover states on interactive elements like buttons and service cards, using Framer Motion.
- Key Call-to-Action buttons will feature subtle pulsing or micro-animations to encourage interaction and reduce friction.
